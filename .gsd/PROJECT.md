# Project

## Name
belevtsov.dev — Personal CV & Portfolio

## Purpose
Interactive CV/portfolio site for Vitalii Belevtsov (Junior Frontend Developer).
Primary goal: hiring conversion — recruiters and tech leads should get all key info within 20 seconds.

## Live
https://belevtsov.dev

## Repos
- Frontend: CV-React (this repo)
- Backend: back-CV-react

## Stack
- Frontend: React 19, Vite 8, plain CSS, @react-pdf/renderer, sonner
- Backend: Node.js, Express 5, Zod, Telegraf, Nodemailer/Brevo, Swagger

## Current status
Active development. Not using TypeScript. No test suite yet.
